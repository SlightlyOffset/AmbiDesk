AmbiDesk

Ambient Workspace Weather & Forecast Companion

อุปกรณ์ตั้งโต๊ะอัจฉริยะที่รายงานสภาพอากาศ อุณหภูมิ และความน่าจะเป็นของฝนแบบ Real-time ผ่านแผงไฟ 12x8 LED Matrix ในตัวบอร์ดและจอ I2C LCD ให้รับรู้สภาพอากาศภายนอกได้ด้วยการเหลือบมอง โดยไม่ต้องสลับหน้าจอหรือหยิบสมาร์ทโฟนขึ้นมาดู

แสดงข้อมูลตัวอย่าง

Features

1. รายงานสภาพอากาศและอุณหภูมิปัจจุบัน

ดึงข้อมูลสภาพอากาศภายนอกและอุณหภูมิ (°C) อัตโนมัติทุก 10 นาทีผ่าน Wi-Fi แสดงไอคอน Pixel Art บน LED Matrix ได้แก่ แดดออก มีเมฆ ฝนตก และฟ้าผ่า/พายุ รวมถึงอุณหภูมิและเปอร์เซ็นต์โอกาสเกิดฝนตก โดยวนแสดงไอคอน (3 วินาที) อุณหภูมิ (2 วินาที) และแจ้งเตือนโอกาสฝนตก (3 วินาที เฉพาะเมื่อ PoP มากกว่า 50%)

2. พยากรณ์สภาพอากาศล่วงหน้า

ตรวจจับความน่าจะเป็นของฝน (PoP) ในชั่วโมงถัดไป และเตือนอัตโนมัติเมื่อสูงเกินเกณฑ์ 50%

3. ปุ่มกดสลับดูช่วงเวลาพยากรณ์

กดปุ่มเพื่อดูพยากรณ์ล่วงหน้าได้ 9 ช่วงเวลา ได้แก่ Now, +1h, +3h, +5h, +12h, +1d, +2d, +3d และ +4d หากไม่กดปุ่มภายใน 20 วินาที ระบบจะกลับมาที่ Now อัตโนมัติ

4. สถาปัตยกรรม Micro-Aggregator (BFF Pattern)

ใช้ Cloudflare Worker ดึงข้อมูลขนาดใหญ่จาก Open-Meteo แล้วย่อให้เหลือ JSON ขนาดประมาณ 60–300 bytes ช่วยป้องกันหน่วยความจำ RAM/Heap เต็มบนไมโครคอนโทรลเลอร์และลดภาระ HTTPS/TLS Handshake

5. ออกแบบตามมาตรฐานระบบฝังตัว

ทำงานด้วย Finite State Machine แบบ Non-blocking (ใช้ millis()) ไม่จองหน่วยความจำแบบไดนามิก (Zero dynamic heap allocation) และจำกัดขอบเขตการวนลูป (Bounded loops)

อุปกรณ์ที่ใช้ในโครงงาน

Arduino UNO R4 WiFiไมโครคอนโทรลเลอร์หลัก (Renesas RA4M1 + ESP32-S3) พร้อมโมดูล Wi-Fi และ LED Matrix 12x8 ในตัว
เบรดบอร์ดแผงต่อวงจรสำหรับเชื่อมต่อปุ่มกดและสายสัญญาณ
ปุ่มกดสวิตช์สำหรับกดเปลี่ยนโหมดและดูพยากรณ์ล่วงหน้า (ต่อที่ขา D2)
สายจัมเปอร์เชื่อมต่อระหว่าง Arduino, เบรดบอร์ด, ปุ่มกด และจอ LCD
จอ LCD 1602 / 2004 พร้อมโมดูล I2Cแสดงข้อความสถานะ อุณหภูมิ และคำอธิบายสภาพอากาศแบบละเอียด

แผนผังการต่อวงจรเบื้องต้น

ปุ่มกด

ขาข้างหนึ่งต่อเข้า D2 ขาอีกข้างต่อเข้า GND โค้ดเปิด Internal Pull-up (INPUT_PULLUP) ไว้แล้ว จึงไม่ต้องใช้ตัวต้านทานภายนอก

จอ LCD (I2C)

GND ต่อ GND, VCC ต่อ 5V, SDA ต่อ SDA (A4), SCL ต่อ SCL (A5) ค่าเริ่มต้น LCD_I2C_ADDR คือ 0x27 ใน include/Config.h ถ้าใช้ชิป PCF8574AT ให้เปลี่ยนเป็น 0x3F

ไลบรารีที่ใช้งาน

bblanchon/ArduinoJson@^7.0.0 สำหรับแปลงข้อมูล JSON จาก Micro-Aggregator และ marcoschwartz/LiquidCrystal_I2C@^1.1.4 สำหรับควบคุมจอ LCD ผ่านบัส I2C PlatformIO ติดตั้งให้อัตโนมัติจาก platformio.ini

การติดตั้งและใช้งาน

1. ฝั่ง Cloud Micro-Aggregator

วิธีที่ 1: Deploy ขึ้น Cloudflare Worker (แนะนำสำหรับใช้งานจริง)

cd worker
npm install
npx wrangler deploy

วิธีที่ 2: รันเซิร์ฟเวอร์จำลองบนเครื่อง (สำหรับทดสอบ)

cd worker
npm install
node dev-server.js

2. ฝั่งฮาร์ดแวร์และเฟิร์มแวร์

ใช้ PlatformIO บน VS Code คัดลอก include/secrets.example.h เป็น include/secrets.h แล้วตั้งค่า

WIFI_SSID และ WIFI_PASSWORD คือชื่อและรหัสผ่าน Wi-Fi
AGGREGATOR_HOST ใส่เฉพาะโดเมนหรือ IP โดยไม่ต้องมี https://
AGGREGATOR_PORT ใช้ 443 (HTTPS) หรือ 3000 (เซิร์ฟเวอร์จำลอง)
AGGREGATOR_PATH ค่าเริ่มต้นคือ "/"
AGGREGATOR_USE_SSL ใช้ true กับ Cloudflare Worker และ false กับเซิร์ฟเวอร์จำลอง

ต่อสาย USB กด Upload แล้วเปิด Serial Monitor ที่ Baud rate 115200
